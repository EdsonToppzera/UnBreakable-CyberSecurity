# UnBreakable - CyberSecurity

Este repositório centraliza as minhas resoluções de desafios (**writeups**) de plataformas de segurança cibernética e competições de CTF, além de **scripts utilitários** e automações desenvolvidas para e durante as atividades do grupo de estudos **UnBreakable**.

O objetivo aqui é documentar o raciocínio lógico usado para explorar vulnerabilidades e catalogar ferramentas que auxiliam na automação de tarefas repetitivas.
